# The source proofs' lemma axioms in transfer runs (exp58b)

Written 22 Nov 2026, 13:32 UTC.

## Question

exp56 and exp58a: given-rule sketches lacked the source run's lemma axioms, and adding them, named by their goals,
proved 13 of 25 and 46 of 59 goals the live loops had failed. Do transfer.py's other runs have the same gap?

## The gap

* A proof's hint file holds its derived steps, not the axioms it used. nslm_to_aa1 1099 (production) used 16 lemma
  axioms (lemma_knn_I_<goal>, lemma_goal_J), and none of them is among its 400 hint lines.
* transfer.py run takes a source proof's hint file as hints. It adds lemma axioms (`--src-lemmas`) only when the
  source's axioms are within the target's, and then only the source's 6 nearest proven siblings, not the lemmas its
  proof used.
* Same-statement runs (the goal's statement proven in a theory with more axioms; givenmatch live, exp/sofree.py)
  never meet that condition, so they get none of the source proof's lemmas. Proof-step transfers (XFL) get siblings,
  not the used lemmas.
* In Z8's live loop (from zero, 22 Nov) the same-statement runs proved 345 of 961. 525 goals failed there and were
  never proved by the loop; Z8 later solved 131 of them by other routes.

## Change

transfer.py run `--src-used` (off by default; the live loops are unchanged). For each source, it reads the proof text
(LIVE_DST/proofs, INIT/proofs or DIR/proofs; exp/proofq.py writes them). It takes the lemma axioms the proof used,
named as exp/trust.py resolves them: lemma_goal_J, lemma_knn_I_<goal>, srclem_I_<goal>, skax_I_<goal>. Each one that
is a proven goal of the context, is not the target, and has axioms within the target's is added as srclem_<k>_<goal>,
with the goal's statement (lemmas.lemma_form). trust.py resolves those names.

## Replay

transfer arguments. For each sampled goal:
* the context is Z8's goals whose hint file is older than the first so_*.tsv file that lists the goal;
* arm used: the run as the live loop made it, plus `--src-used`;
* arm ctl, 20 of the 100: the same run unchanged;
* 20 s, `--src-lemmas 6`, 1 worker.

Started 13:32 (PID 2066925), log loops/SORP.log, rows loops/SORP/replay.tsv. About 70 minutes.

## Measures and decision

* used: proved of 100, of those Z8 never solved, and how much earlier for the others. ctl: proved of 20, expected
  near 0. The lemma axioms added per run, and how many runs got none (those cannot change).
* Soundness: proofq rerun of the proved runs, and every axiom line checked against the context.
* If used beats the control rate by 10+ of 100, production's live loops (GML's same-statement runs, XFL) get it.
  Production's proof texts are current (the proof queue caught up at about 12:50). From zero the texts lag, so
  there loop.py would have to record each proof's USEDAXIOMS at search time first.
